# Руководство пользователя

## 1. Назначение

CodeMatrix Elemmass выполняет массовые операции над элементами инфоблоков 1С-Битрикс. Пользователь выбирает инфоблок, при необходимости ограничивает выборку разделами и фильтром, затем запускает одно из доступных действий.

Модуль работает с инфоблоками и, для соответствующих операций, с данными торгового каталога. Для работы необходимы установленные и доступные модули 1С-Битрикс `iblock`; отдельные операции используют API каталога и файлового менеджера.

## 2. Установка и удаление

1. Разместите каталог модуля в `/bitrix/modules/codematrix.elemmass/`.
2. В административной панели откройте раздел установки Marketplace/модулей и установите модуль `CodeMatrix Elemmass`.
3. Убедитесь, что модуль появился в административном меню.
4. Проверьте права групп пользователей на модуль.

Установщик регистрирует модуль, выполняет SQL из `install/db/<тип_БД>/install.sql` и копирует административные файлы, JavaScript и CSS в каталоги Битрикс.

При удалении установщик удаляет таблицу профилей и установленные файлы модуля. Перед удалением сделайте резервную копию. Не рассчитывайте на сохранение профилей после полного удаления модуля.

## 3. Права доступа

Доступ к административной странице определяется правами группы на модуль:

- `R` — просмотр страницы и настроек;
- `W` или выше — запуск массовой операции и сохранение профилей.

Фактические права назначаются в настройках прав доступа модуля в административной панели. Проверяйте их под той учетной записью, которая будет выполнять задания.

## 4. Выполнение массовой операции

1. Откройте административную страницу «Массовые операции с элементами инфоблоков».
2. Выберите инфоблок.
3. При необходимости выберите один или несколько разделов.
4. Включите «Включая подразделы», если нужно учитывать вложенные разделы.
5. Настройте фильтр.
6. Выберите действие в группе «Действие».
7. Заполните параметры выбранного действия.
8. Проверьте инфоблок, разделы, фильтр и настройки.
9. Нажмите «Выполнить действия» и дождитесь завершения.

Процесс выполняется последовательными AJAX-запросами ограниченными по времени шагами. На странице отображается ход выполнения и количество успешно обработанных элементов и элементов с ошибками. Не закрывайте страницу до завершения интерактивного запуска.

**Важно:** перед запуском проверьте резервную копию. Для первой проверки ограничьте выборку несколькими тестовыми элементами. Удаление и изменение данных могут быть необратимыми.

## 5. Разделы и фильтры

Фильтр формируется из условий по доступным полям и свойствам выбранного инфоблока, а также доступным полям торгового каталога.

Общие типы сравнений, предусмотренные кодом:

- равно / не равно;
- больше, больше или равно;
- меньше, меньше или равно;
- задано / не задано;
- содержит / не содержит;
- начинается с / не начинается с;
- оканчивается на / не оканчивается на;
- для дат — позднее чем / ранее чем.

Набор доступных сравнений зависит от типа поля или свойства. Для списочных свойств доступны значения списка. Условия фильтра передаются в API выборки элементов инфоблока.

Разделы ограничивают область обработки. Если раздел не выбран, выборка не ограничивается конкретным разделом. Поведение вложенных разделов задается отдельным флажком.

## 6. Действия, присутствующие в текущем коде

В каталоге `include/actions/` обнаружены 15 встроенных действий. Подробные параметры, особенности реализации и известные ограничения каждого действия приведены в [справочнике массовых действий](ACTIONS_REFERENCE.md).

Список действий:

| Действие | Назначение |
| --- | --- |
| Генерация символьного кода | Формирование CODE из выбранного поля или свойства с параметрами транслитерации, регистра, длины и уникальности |
| Заполнение значений | Массовое заполнение доступных полей, свойств и параметров каталога |
| Замена в тексте | Поиск и замена текста; предусмотрены настройки регулярных выражений и чувствительности к регистру |
| Пересохранение элементов инфоблоков | Повторное сохранение элементов для запуска обработчиков Битрикс |
| Удаление элементов | Удаление выбранных по фильтру элементов |
| Привязки к разделам | Изменение привязок элементов к разделам |
| Логирование | Выгрузка названий или выбранных полей элементов в TXT/CSV-файл |
| Пересчет цен — наценки и скидки | Изменение цен по заданным правилам |
| Копирование цен | Копирование значений между поддерживаемыми источниками и целями цен |
| ТП: установка цены из родительского товара | Установка цены торгового предложения на основе родительского товара |
| Создание наборов/комплектов | Создание наборов или комплектов средствами поддерживаемого API каталога |
| Копирование изображений | Копирование изображений между поддерживаемыми полями и свойствами |
| Удаление изображений, файлов | Удаление файловых значений в рамках поддерживаемых полей и свойств |
| Ресайз изображений | Изменение размеров изображений |
| Обработка модулем «Обработчик изображений» | Передача изображений на обработку внешнему модулю «Обработчик изображений» |

Наличие действия в списке не означает, что оно применимо к любому типу данных. Перед использованием изучите описание и настройки конкретного действия на странице модуля. Для внешнего обработчика изображений требуется соответствующий сторонний модуль.

В частности, действие «Заполнение значений» прямо сообщает об ограничениях: не поддерживаются поля «Картинка для анонса» и «Детальная картинка», а также свойства типов «Файл» и «Видео».

## 7. Профили

Профиль — сохраненный набор параметров массовой операции: инфоблок, разделы, настройка учета подразделов, фильтр, выбранное действие и его параметры.

### Сохранение

1. Настройте инфоблок, разделы, фильтр и действие.
2. Нажмите «Сохранить профиль».
3. Введите название.

Для сохранения требуется выбранный инфоблок и действие.

### Повторное использование

На странице массовых операций выберите «Использовать профиль» и укажите сохраненный профиль. Его настройки будут загружены в форму. Перед запуском проверьте загруженные параметры: профиль может содержать условия, которые больше не соответствуют текущей задаче.

### Управление

На странице «Управление профилями» можно просматривать список, фильтровать его по основным полям и удалять профили. В списке доступны сведения об инфоблоке, разделах, фильтре, действии и датах.

## 8. Автоматический запуск через Cron

Модуль содержит файл `cron.php`. Он загружает ядро Битрикс и запускает профиль, переданный аргументом `profile`.

1. Создайте и проверьте профиль вручную.
2. Запишите его числовой ID.
3. На странице управления профилями используйте действие получения команды запуска для Cron.
4. Проверьте сформированную команду в окружении сервера и настройте ее в системном планировщике.
5. Проверьте журнал/результат выполнения и при необходимости настройте почтовые уведомления.

Пример общей формы команды (пути зависят от сервера):

```bash
/usr/bin/php -f /path/to/bitrix/modules/codematrix.elemmass/cron.php profile=123
```

Если CLI PHP использует отличающуюся от сайта кодировку или настройки `mbstring`, создайте файл `php.ini` в каталоге модуля с необходимыми настройками и передайте его PHP через `-c`:

```bash
/usr/bin/php -c /path/to/bitrix/modules/codematrix.elemmass/php.ini -f /path/to/bitrix/modules/codematrix.elemmass/cron.php profile=123
```

Не копируйте пример с путями без адаптации к своему серверу. Команду запуска и пользователя Cron должен проверить системный администратор.

## 9. Уведомления и диагностика

В языковых файлах модуля предусмотрено почтовое уведомление об успешном завершении задания Cron с именем профиля, выбранным действием, количеством элементов, счетчиками успехов/ошибок и временем выполнения. Проверьте наличие и настройки почтового типа события и шаблона на конкретном сайте.

Если задание не запускается:

- проверьте, что модуль и инфоблок доступны;
- проверьте ID профиля и то, что профиль не удален;
- проверьте права на запуск;
- проверьте путь к PHP CLI и доступность файла `cron.php`;
- сравните настройки кодировки веб-PHP и CLI PHP;
- проверьте журнал PHP и журнал Битрикс.
