# Справочник массовых действий

Документ описывает встроенные действия, обнаруженные в `include/actions/` ветки `main`. Названия параметров и поведение сверены с формами `ShowSettings()` и обработчиками `Process()`.

> Перед применением любого действия сделайте резервную копию. Сначала выполните его на тестовом инфоблоке или небольшой выборке. Описание не заменяет проверку поведения на конкретной версии 1С-Битрикс и конфигурации каталога.

## Как читать справочник

- **Источник** — поле/свойство, из которого действие берет значение.
- **Цель** — поле/свойство, которое действие изменяет.
- **Профиль** — сохраненные параметры действия и выборки.
- Указанные значения по умолчанию — значения, заданные непосредственно в форме. Если значение не указано, форма не задает явного значения либо оно зависит от выбранного инфоблока и конфигурации сайта.

## Общие правила выполнения

Модуль выбирает элементы по фильтру и обрабатывает их в порядке возрастания ID. Обработка разбивается на серверные шаги, чтобы не выполнять весь набор в одном HTTP-запросе. Счетчик «успешно» зависит от boolean-результата метода действия, а не от независимой проверки каждого измененного значения в базе.

Поэтому у отдельных действий есть особенности учета результата. В частности, действие копирования цены родительского товара в торговое предложение в текущем коде возвращает `false` независимо от результата вызова записи цены. Подробности приведены в соответствующем разделе.

## 1. Генерация символьного кода

- **Код действия:** `CODE_GENERATION`
- **Класс:** `CME_CodeGeneration`
- **Группа:** Общие
- **Файл:** `include/actions/CodeGeneration.php`

Генерирует `CODE` элемента из выбранного поля или свойства.

### Настройки

| Параметр | Назначение | Значение формы |
| --- | --- | --- |
| Поле / свойство | Источник исходного текста | Не выбрано |
| Транслит | Преобразовать текст в латиницу через `CUtil::translit` | Включено |
| Тримминг | Удалить пробелы в начале и конце | Включено |
| Проверка уникальности | Проверять наличие такого символьного кода | Включено |
| Удалять лишние символы замены | Схлопывать повторяющиеся символы замены | Включено |
| Регистр | Не менять, нижний или верхний | Не менять |
| Ограничение длины | Максимальная длина результата | 100 |
| Замена пробелов | Символ вместо пробелов | `-` |
| Замена спецсимволов | Символ вместо неподдерживаемых символов | `_` |
| При совпадении | Добавить индекс, ID раздела, ID элемента и т. п. либо пропустить | Добавить порядковый индекс |
| Текст в начале / конце | Добавить префикс и/или суффикс | Пусто |

### Порядок работы и ограничения

1. Значение берется из выбранного поля или свойства. Для множественного свойства фактически используется первое значение.
2. Применяются тримминг, удаление кавычек `&quot;`, транслитерация/замена символов, регистр и ограничение длины.
3. При включенной уникальности выполняется проверка существующего кода и выбирается суффикс согласно настройке.
4. Результат записывается в поле `CODE`.

В текущем обработчике источниками напрямую обрабатываются стандартные поля `ID`, `NAME`, `SORT`, `EXTERNAL_ID` и свойства вида `PROPERTY_ID`. Не выбирайте в качестве источника неподдерживаемое поле.

**Известное расхождение в коде:** форма предлагает вариант `add_element_id`, а одна из веток обработчика сравнивает значение с `element_id`. Поэтому вариант добавления ID элемента требует отдельной проверки на стенде; документация не обещает, что он сработает как подписано в интерфейсе.

## 2. Заполнение значений

- **Код действия:** `SET_VALUES`
- **Класс:** `CME_SetValues`
- **Группа:** Общие
- **Файл:** `include/actions/SetValues.php`

Устанавливает заданное значение для выбранного поля, свойства или поддерживаемого параметра торгового каталога.

### Настройки

1. Выберите целевое поле, свойство, цену или параметр каталога.
2. После выбора интерфейс загружает форму значения с учетом типа выбранного поля.
3. Для части числовых полей и строковых значений доступны дополнительные способы генерации:
   - **Счетчик:** заменяет маркер `#VALUE#` на последовательность. Настраиваются шаг и первое значение.
   - **Случайное число:** генерирует значение в указанном диапазоне.
4. Для цены торгового каталога может быть доступен выбор валюты и наценки каталога. Если выбрана наценка, применяется она; иначе используется введенная цена.

### Поддерживаемые группы целей

- Стандартные поля элемента: название, символьный код, сортировка, внешний/XML ID, активность, тексты анонса и детального описания, типы текста, даты активности, счетчик просмотров, теги и ряд служебных полей.
- Свойства инфоблока, для которых форма Битрикс может построить редактор значения. Особые типы обрабатываются отдельными ветками.
- Цены торгового каталога и закупочная цена.
- Параметры каталога: остаток, зарезервированное количество, количественный учет, разрешение покупки при нулевом остатке, подписка, НДС, ставка НДС, вес, габариты, единица измерения, коэффициент единицы измерения и остатки по складам.
- SEO-поля, добавляемые интерфейсом действия.

### Ограничения

Описание самого действия прямо указывает, что не поддерживаются поля «Картинка для анонса» и «Детальная картинка», а также свойства типов «Файл» и «Видео». Не используйте действие для массовой загрузки/замены изображений или файлов.

Для свойств типа «Последовательность» проверьте разрешение изменения значений в настройках свойства инфоблока. Значение может не сохраниться, если запись запрещена.

Для полей текста анонса и детального текста отдельно выбирается тип содержимого: текст или HTML. Перед массовой записью HTML проверьте разметку и экранирование.

## 3. Замена в тексте

- **Код действия:** `REPLACE_TEXT`
- **Класс:** `CME_ReplaceText`
- **Группа:** Общие
- **Файл:** `include/actions/ReplaceText.php`

Выполняет поиск и замену в выбранном текстовом поле или свойстве.

### Настройки

| Параметр | Назначение |
| --- | --- |
| Поле или свойство | Цель замены |
| Что ищем | Искомая строка или шаблон регулярного выражения |
| На что заменяем | Новое значение; при регулярном выражении может использовать обратные ссылки PHP PCRE |
| Использовать регулярные выражения | Включает режим регулярного выражения |
| Учитывать регистр | Делает поиск чувствительным к регистру |

В форме по умолчанию регулярные выражения и учет регистра выключены.

### Поддерживаемые цели

Обработчик явно поддерживает стандартные поля `NAME`, `CODE`, `EXTERNAL_ID`, `XML_ID`, `PREVIEW_TEXT`, `DETAIL_TEXT`, `TAGS`, а также свойства вида `PROPERTY_ID`.

Для множественного свойства замена выполняется по каждому значению. Для стандартного поля используется исходное значение с префиксом `~`, чтобы не потерять исходное содержимое.

### Пример

Найти `ARTICUL_(\d+)` и заменить на `art_$1_new` можно при включенном режиме регулярных выражений. Перед применением проверьте шаблон на нескольких реальных строках.

**Осторожно:** неверный шаблон или слишком общий текст поиска может изменить большое количество записей. Для первого запуска задайте узкий фильтр.

## 4. Пересохранение элементов инфоблоков

- **Код действия:** `ELEMENT_UPDATE`
- **Класс:** `CME_ElementUpdate`
- **Группа:** Общие
- **Файл:** `include/actions/ElementUpdate.php`

Повторно вызывает методы обновления Битрикс без передачи изменяемых полей.

### Настройки

Можно включить один или оба пункта:

- `CCatalogProduct::Update` — обновление записи товара каталога (показывается, если установлен модуль `catalog`);
- `CIBlockElement::Update` — обновление элемента инфоблока.

Оба флажка в форме изначально включены. Если снять оба, клиентская проверка не должна разрешить запуск.

### Когда использовать

Применяйте, когда нужно повторно вызвать штатную логику обновления/обработчики Битрикс для уже существующих элементов или товаров. Действие не задает новые значения полей само по себе.

Проверяйте побочные эффекты обработчиков событий, сторонних модулей и интеграций: повторный вызов обновления может запускать пользовательский код сайта.

## 5. Удаление элементов

- **Код действия:** `DELETE`
- **Класс:** `CME_Delete`
- **Группа:** Общие
- **Файл:** `include/actions/Delete.php`

Удаляет каждый элемент, попавший в текущую выборку, через `CIBlockElement::Delete($ElementID)`. Отдельных параметров у действия нет.

Успех учитывается, если API удаления вернул успешный результат. Действие не содержит отдельного алгоритма обхода связанных торговых предложений или удаления их по связи с родительским товаром. Перед удалением каталожных товаров проверьте структуру SKU, предложения, наборы/комплекты, заказы и другие связи на копии сайта.

**Операция потенциально необратима.** Не запускайте ее без резервной копии и проверки фильтра на малой выборке.

## 6. Привязки к разделам

- **Код действия:** `LINK_SECTION`
- **Класс:** `CME_LinkSection`
- **Группа:** Общие
- **Файл:** `include/actions/LinkSection.php`

Изменяет привязку выбранных элементов к одному указанному разделу.

### Настройки

| Параметр | Варианты |
| --- | --- |
| Тип операции | Перенести в раздел; добавить привязку; удалить привязку |
| Раздел | Один раздел выбранного инфоблока |

### Поведение

- **Перенести в раздел (`set`)** — обновляет основное поле `IBLOCK_SECTION_ID`.
- **Добавить привязку (`add`)** — получает текущие разделы элемента, добавляет выбранный ID и сохраняет уникальный список.
- **Удалить привязку (`del`)** — исключает выбранный ID из списка текущих разделов и сохраняет оставшиеся привязки.

После успешной операции обработчик дополнительно вызывает обновление элемента с полем `WD=Y`. Это техническая особенность реализации.

Проверьте основной раздел и множественные привязки: режим переноса и режим добавления не равнозначны.

## 7. Логирование в файл

- **Код действия:** `LOGGER`
- **Класс:** `CME_Logger`
- **Группа:** Общие
- **Файл:** `include/actions/Logger.php`

Сохраняет данные выбранных элементов в текстовый файл или CSV.

### Настройки

| Параметр | Назначение | Значение формы |
| --- | --- | --- |
| Формат | TXT или CSV | TXT |
| Имя файла | Путь относительно корня сайта; символ `#` заменяется расширением | `/bitrix/modules/codematrix.elemmass/!log.#` |
| Кодировка | windows-1251 или UTF-8 | windows-1251 |
| Поля CSV | Выбор и сортировка полей для выгрузки | Не применяется для TXT |

### Форматы

- **TXT:** записывает ID и название элемента в строку вида `[ID] Название`.
- **CSV:** записывает заголовок и выбранные значения. Разделитель в текущем коде — точка с запятой. Значения заключаются в кавычки, внутренние кавычки удваиваются. Для файлов доступны пути к изображениям; множественные значения соединяются запятой.

Для CSV список полей должен быть непустым. Доступны стандартные поля, свойства, цены и поддерживаемые поля каталога.

### Важные особенности записи

При первом элементе нового запуска существующий файл по указанному пути удаляется, после чего файл создается заново. Запись идет в режиме добавления, с блокировкой файла на время записи.

Убедитесь, что PHP-процесс имеет права на запись в целевой каталог. Указывайте контролируемый путь внутри корня сайта и не направляйте файл в публично доступный каталог, если выгрузка содержит закрытые данные. Не используйте пользовательский ввод для построения имени файла.

## 8. Пересчет цен — наценки и скидки

- **Код действия:** `PRICE_CHANGE`
- **Класс:** `CME_PriceChange`
- **Группа:** Цены
- **Файл:** `include/actions/PriceChange.php`

Изменяет значение выбранного источника цены. В отличие от действия копирования, источник одновременно является полем, куда записывается результат.

### Настройки

| Параметр | Назначение | Значение формы |
| --- | --- | --- |
| Цена | Свойство инфоблока, тип цены каталога или закупочная цена | Не выбрано |
| Значение наценки/скидки | Число или процент со знаком | `+10%` |
| Пересчет относительно закупочной цены | Использовать закупочную цену как базу | Выключено |
| Округление | Включить округление и выбрать разряд | Выключено; разряд «целых» |
| Формат | Форматирование результата при записи в свойство | Выключено |
| Применить для торговых предложений | Повторить пересчет для предложений товара | Выключено |
| Минимальная цена относительно закупочной | Ограничить снижение цены | Выключено; `+10%` |

### Формат изменения

- `+10%` или `10%` — увеличить на 10 процентов;
- `-10%` — уменьшить на 10 процентов;
- `+200` или `200` — прибавить 200;
- `-200` — вычесть 200.

Отрицательный результат ограничивается нулем.

### Округление

В интерфейсе доступны разряды: тысячи, сотни, десятки, целые и десятые. Для свойства инфоблока можно включить форматирование результата. Для цены каталога значение записывается числом, а формат отображения определяется настройками валют/каталога.

### Закупочная цена и торговые предложения

При включении «Пересчет относительно закупочной цены» исходной базой становится закупочная цена товара. Опция минимальной цены задает нижнюю границу относительно закупочной цены, например закупочная цена плюс 10%.

Если включено применение для торговых предложений, обработчик находит предложения, связанные с текущим товаром, и запускает пересчет для каждого из них. Проверяйте валюту и типы цен у товара и предложений до запуска.

## 9. Копирование цен

- **Код действия:** `PRICE_COPY`
- **Класс:** `CME_PriceCopy`
- **Группа:** Цены
- **Файл:** `include/actions/PriceCopy.php`

Копирует числовое значение между источником и целью. Источником и целью могут быть свойства инфоблока, типы цен торгового каталога и закупочная цена — если соответствующий API каталога доступен.

### Настройки

| Параметр | Назначение | Значение формы |
| --- | --- | --- |
| Откуда взять | Источник цены | Не выбрано |
| Куда записать | Целевое свойство/цена | Не выбрано |
| Не устанавливать нулевые цены | Пропускать нулевое значение источника | Выключено |
| Округлить | Округление результата | Выключено; целые |
| Формат | Форматирование при записи в свойство | Выключено |
| Валюта | Пересчитать в выбранную валюту | Выключено |

### Особенности

- При включенной опции «Не устанавливать нулевые цены» элемент с нулевой ценой пропускается и учитывается как успешно пропущенный.
- Пересчет валюты использует модуль `currency` и доступный коэффициент конвертации.
- Форматирование применяется при записи в свойство инфоблока. Для цены каталога сохраняется числовое значение и валюта.
- Для источника-свойства значение читается как число; для множественного свойства используется первое значение.

Не копируйте строковые значения с произвольными символами валюты, если свойство не содержит чистое число. Перед массовой конвертацией проверьте актуальность курсов и валюты источника.

## 10. ТП: установка цены из родительского товара

- **Код действия:** `COPY_OFFER_PRICE`
- **Класс:** `CME_CopyOfferPrice`
- **Группа:** Цены
- **Файл:** `include/actions/CopyOfferPrice.php`

Предназначено для запуска на инфоблоке торговых предложений. Выбирается тип цены предложения, а значение берется из соответствующего типа цены родительского товара.

### Настройки

- **Тип цен:** целевой тип цены торгового предложения.

Обработчик определяет инфоблок предложений, ID инфоблока товаров и свойство связи SKU. По значению свойства связи находит родительский товар, считывает его цену и вызывает установку цены у предложения.

### Критическое замечание о текущем коде

В текущей реализации метод `Process()` инициализирует результат как `false`, вызывает `SetProductPrice()`, но не присваивает результату успешное значение и в конце возвращает `false`. Поэтому интерфейс может посчитать обработку неуспешной даже при фактической записи цены. Кроме того, результат вызова `SetProductPrice()` не проверяется.

До исправления и отдельного тестирования не используйте счетчики успешности этого действия как достоверное подтверждение записи. После запуска проверяйте цены предложений непосредственно в каталоге.

## 11. Копирование изображений

- **Код действия:** `IMAGE_COPY`
- **Класс:** `CME_ImageCopy`
- **Группа:** Изображения
- **Файл:** `include/actions/ImageCopy.php`

Копирует файл из одного поля/свойства элемента в другое.

### Источник и цель

Поддерживаются:
- поле «Картинка для анонса» (`PREVIEW_PICTURE`);
- поле «Детальная картинка» (`DETAIL_PICTURE`);
- свойства инфоблока типа «Файл» (`PROPERTY_ID`).

Можно сочетать поле и файловое свойство. Источник и цель должны различаться.

### Особенности

Для полей изображения файл копируется через файловый API и обновление элемента. Для свойства используется `SetPropertyValuesEx`. Если источник множественный, обработка зависит от множественности целевого свойства; при копировании в обычное поле берется первое значение.

Не путайте копирование файлового значения с копированием всех метаданных/описаний свойства. Проверяйте результат на одиночных и множественных свойствах.

## 12. Удаление изображений и файлов

- **Код действия:** `IMAGE_DELETE`
- **Класс:** `CME_ImageDelete`
- **Группа:** Изображения
- **Файл:** `include/actions/ImageDelete.php`

Удаляет изображения или файловые значения из выбранных полей и свойств.

### Настройки

Можно выбрать несколько полей/свойств одновременно. Обработчик распознает `PREVIEW_PICTURE`, `DETAIL_PICTURE` и свойства вида `PROPERTY_ID`.

Для стандартных полей передается флаг удаления файла; для свойства вызывается `SetPropertyValuesEx` со значением `del=Y`.

**Внимание:** действие изменяет файловые данные элементов. Убедитесь, что выбран правильный список свойств и полей. Результат операции проверяйте в карточке элемента и файловом хранилище.

## 13. Ресайз изображений

- **Код действия:** `IMAGE_RESIZE`
- **Класс:** `CME_ImageResize`
- **Группа:** Изображения
- **Файл:** `include/actions/ImageResize.php`

Уменьшает изображения, превышающие заданные габариты. Поддерживаются поля анонса/детальной картинки и свойства типа «Файл».

### Настройки

| Параметр | Назначение | Значение формы |
| --- | --- | --- |
| Поля / свойства с изображениями | Можно выбрать несколько | Не выбрано |
| Метод | Вписать пропорционально; заполнить размер с обрезкой; альтернативный пропорциональный режим | Вписать пропорционально |
| Ширина | Максимальная ширина в пикселях | 1000 |
| Высота | Максимальная высота в пикселях | 1000 |
| Резкость | Применить фильтр Sharpen | Включено |

Ресайз выполняется через `CFile::ResizeImageGet`. Для одиночного поля изображение изменяется только если ширина или высота превышает заданный предел. Для множественного файлового свойства проверка и обновление выполняются по массиву значений.

Это действие не предназначено для увеличения маленьких изображений. Выберите размеры и метод с учетом макета сайта; обрезка в режиме exact может удалить часть изображения.

## 14. Создание наборов/комплектов

- **Код действия:** `PRODUCT_SET`
- **Класс:** `CME_ProductSet`
- **Группа:** Общие
- **Файл:** `include/actions/ProductSet.php`

Создает или обновляет набор/комплект для каждого обрабатываемого товара через `CCatalogProductSet`. Требуется установленный модуль `catalog` и доступный класс `CCatalogProductSet`.

### Настройки

- **Тип:** набор или комплект.
- **Состав:** список товаров, добавляемых в набор/комплект.
- **Количество:** количество каждого компонента; значение формы по умолчанию — 1.
- **Сортировка:** порядок компонента; значение формы по умолчанию — 100.
- **Процент:** процент скидки для компонента в режиме «комплект».
- **Удалить:** убрать строку товара из формы.

Товар добавляется через выбор элемента каталога. Требуется как минимум один товар. Для комплекта сумма процентов не должна превышать 100; для всех компонентов должно быть указано количество.

### Важное различие типов

В коде значение `set_type=1` соответствует `CCatalogProductSet::TYPE_SET` (комплект), а `set_type=2` — `CCatalogProductSet::TYPE_GROUP` (набор). Не ориентируйтесь только на внутренние числовые значения API.

Если у товара уже есть набор/комплект выбранного типа, действие обновляет найденную запись; если нет — создает новую. При обновлении выполняется пересчет наборов. Ошибки API записываются в журнал модуля.

## 15. Обработка модулем «Обработчик изображений»

- **Код действия:** `WEBDEBUG_IMAGE`
- **Класс:** `CME_WebdebugImage`
- **Группа:** Изображения
- **Файл:** `include/actions/WebdebugImage.php`

Передает изображения в установленный сторонний модуль `webdebug.image` по выбранному профилю обработки и сохраняет результат в другое поле/свойство.

### Настройки

1. Источник — поле анонса, детальная картинка или файловое свойство.
2. Цель — поле анонса, детальная картинка или файловое свойство.
3. Профиль обработки изображений из модуля Webdebug.

Если `webdebug.image` не установлен, форма вместо настроек показывает сообщение об отсутствии модуля.

### Особенности и ограничения

- Для запуска требуется выбрать профиль обработки.
- Для стандартного поля при множественном источнике берется первое значение.
- Для множественного целевого свойства обработчик передает значения по каждому файлу.
- В ходе обработки модуль ведет список файлов, которые затем удаляет из файловой системы. Проверяйте настройки профиля и результат на копии сайта, чтобы не потерять исходники, используемые другими элементами.
