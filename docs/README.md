# Документация CodeMatrix Elemmass

Документы описывают состояние модуля в ветке `main`. При расхождении с историческим описанием приоритет имеет текущий код.

## Руководства

- [Руководство пользователя](USER_GUIDE.md) — установка, массовая обработка, фильтры, профили и запуск по Cron.
- [Справочник действий](ACTIONS_REFERENCE.md) — параметры, поведение, ограничения и особенности всех 15 встроенных действий.
- [Архитектура модуля](ARCHITECTURE.md) — структура файлов, обработка заданий, права и клиентская часть.
- [Разработка и расширение](DEVELOPMENT.md) — локальная проверка, устройство плагинов и события расширения.

## Важные оговорки

- Идентификатор модуля: `codematrix.elemmass`.
- Версия в `install/version.php` — `1.0`, дата в файле — 2017-12-01. Это значение метаданных, а не подтверждение актуальной совместимости со всеми версиями PHP или 1С-Битрикс.
- Проверки CI подтверждают синтаксическую совместимость проверяемого кода на настроенной матрице PHP и проверку JavaScript. Они не заменяют тестирование на реальном стенде 1С-Битрикс.
- Перед массовыми операциями обязательно создавайте резервную копию и сначала проверяйте действие на ограниченной выборке.
