# CodeMatrix Elemmass

**Модуль для массовой обработки элементов инфоблоков в 1С-Битрикс.**

## О проекте

CodeMatrix Elemmass — переименованная версия модуля массовых операций с элементами инфоблоков. Репозиторий приведён в соответствие с новым именем модуля, а административный интерфейс переведён на **Vanilla JavaScript** без зависимости от jQuery.

- **Идентификатор модуля:** `codematrix.elemmass`
- **Платформа:** 1С-Битрикс: Управление сайтом
- **Основная ветка:** `main`

## Возможности

Модуль позволяет выбирать элементы инфоблоков по разделам и фильтрам и выполнять над ними массовые операции: изменение полей и свойств, обработку текста и изображений, работу с ценами и параметрами каталога, удаление элементов и другие предусмотренные кодом действия.

Доступны сохранение настроек в профили и запуск сохраненных профилей из системного планировщика Cron.

## Важно

Перед массовыми операциями создавайте резервную копию сайта и сначала проверяйте действие на небольшой тестовой выборке. Прохождение CI-проверок не заменяет тестирование на реальном стенде 1С-Битрикс.
