# CodeMatrix Elemmass

**Модуль для массовой обработки элементов инфоблоков в 1С-Битрикс.**

## О проекте

CodeMatrix Elemmass — переименованная версия модуля массовых операций с элементами инфоблоков. Репозиторий подготовлен под новое имя модуля и бренд **CodeMatrix STUDIO**, а административный интерфейс переведён на **Vanilla JavaScript** без зависимости от jQuery.

На этом этапе сохранены исходное назначение и функциональность проекта. Изменения затрагивают переименование и техническое обновление административного интерфейса, без расширения возможностей модуля.

- **Идентификатор модуля:** `codematrix.elemmass`
- **Платформа:** 1С-Битрикс: Управление сайтом
- **Ветка `main`:** актуальная версия модуля после переименования и перехода на Vanilla JavaScript

## Назначение

Модуль предназначен для массового выполнения операций над элементами инфоблоков. Он позволяет отбирать элементы с помощью фильтров и применять к найденным элементам предусмотренные модулем действия.

Подробный перечень возможностей, инструкции, примеры настройки, описание профилей и руководство по созданию плагинов вынесены из основного README в отдельный документ:

**[Историческая документация исходного модуля](docs/legacy/README.original.md).**
