# CodeMatrix Elemmass

**Модуль для массовой обработки элементов инфоблоков в 1С-Битрикс.**

## О проекте

CodeMatrix Elemmass — переименованная версия модуля массовых операций с элементами инфоблоков. Репозиторий подготовлен под новое имя модуля и бренд **CodeMatrix STUDIO**.

На этом этапе сохранены исходное назначение и функциональность проекта. Это перенос и переименование, а не переработка логики или расширение возможностей. Работа над следующей версией ведётся отдельно в ветке [v2-development](https://github.com/codematrix-studio/codematrix.elemmass/tree/v2-development).

- **Идентификатор модуля:** `codematrix.elemmass`
- **Платформа:** 1С-Битрикс: Управление сайтом
- **Ветка `main`:** версия после переименования, без плановых изменений функциональности
- **Ветка `v2-development`:** разработка следующей версии

## Назначение

Модуль предназначен для массового выполнения операций над элементами инфоблоков. Он позволяет отбирать элементы с помощью фильтров и применять к найденным элементам предусмотренные модулем действия.

Подробный перечень возможностей, инструкции, примеры настройки, описание профилей и руководство по созданию плагинов вынесены из основного README в отдельный документ:

**[Историческая документация исходного модуля](docs/legacy/README.original.md).**

> Документ является архивным описанием исходной версии. Его формулировки и инструкции не следует считать подтверждением актуального состояния каждой функции в текущем проекте без сверки с кодом.
